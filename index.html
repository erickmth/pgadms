 Sobre o Projeto

                                        
Este sistema foi desenvolvido para gerenciar as escalas de limpeza do Formare, proporcionando uma solução eficiente e organizada para a divisão de tarefas entre os alunos.


                                        
 Tecnologias Utilizadas

    • 
                                            
  • Backend: Python, Flask
    • 
                                            
  • Banco de Dados: SQLite
    • 
                                            
  • Hospedagem: PythonAnywhere
