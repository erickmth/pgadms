 Sobre o Projeto
                                            

                                            

                                                Originalmente desenvolvido para gerenciar as escalas de limpeza do
                                                Formare, o sistema evoluiu para uma solução completa de
                                                gestão de frequência e comunicados. Atualmente atende
                                                múltiplas regiões no Sul do Brasil (Curitiba,
                                                Joinville, Pomerode), com expansão planejada para outras localidades.

Novidade — Atualização 20/07/2026 (v12.0.9)

                        

                        

                          

 Nova atualização! O sistema recebeu melhorias no controle de requisições, aumentando os limites de uso da API para proporcionar mais estabilidade e desempenho, mesmo com vários usuários realizando envios simultâneos.

Além disso, a permissão de localização durante o envio da lista de presença agora é opcional. O sistema continuará solicitando a localização para garantir mais segurança e confiabilidade nos registros, porém a chamada poderá ser enviada mesmo sem a autorização da localização.
