# 🏫 Página de Administração de Representantes – Formare Oppi

Plataforma criada para auxiliar os representantes de sala no Instituto Robert Bosch (CTP Curitiba), com foco em organização e administração visual.

## 📌 Sobre o Projeto
Página voltada para facilitar o gerenciamento de tarefas e funções dos representantes de turma, dentro do programa Formare.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript (para navegação e interatividade)

## ▶️ Como Usar
Abra `index.html` no navegador. A navegação entre seções é direta, focada em usabilidade por representantes.
